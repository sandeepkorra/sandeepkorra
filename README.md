
# 🌿 AAROGYA DRISHTI
### Healthcare Support Platform | MERN Stack

AAROGYA DRISHTI is a healthcare-focused web application designed to improve access to healthcare information and support for rural and tribal communities.

## ⚙️ Installation

### Step 1: Clone Repository

```bash
git clone https://github.com/sandeepkorra/Aarogya-drishti.git
```

### Step 2: Install Frontend

```bash
cd client
npm install
```

### Step 3: Install Backend

```bash
cd server
npm install
```

### Step 4: Run Project

```bash
npm run dev
```

Use the appropriate start command in each folder's package.json.

## 🔐 Security

- Secure user authentication.
- Protect patient information.
- Keep API keys and passwords private.
- Never upload `.env` files to GitHub.
